
BlogDeCafé
Este es un proyecto de sitio web para un blog de café, creado para compartir consejos, recetas y cursos relacionados con el mundo del café.

Descripción
BlogDeCafé es un espacio en línea dedicado a los amantes del café que buscan aprender más sobre los diferentes tipos de granos, recetas deliciosas y participar en cursos y talleres relacionados con la extracción y preparación del café.

Características
Artículos Informativos: Explora nuestro blog que presenta artículos informativos sobre tipos de granos de café, recetas deliciosas y beneficios para la salud del café.

Cursos y Talleres: Descubre nuestros cursos y talleres sobre técnicas de extracción de café y recetas para principiantes.

Diseño Responsivo: El sitio web está diseñado para ser accesible desde dispositivos móviles, tabletas y computadoras de escritorio.

Tecnologías Utilizadas
